# VeriFYD Lens Product Specification
## Tagline: Don't Download Blind.

### Core promise
One install. One trust layer between the user and a download.

### Result model
Security Score: malware, phishing, dangerous links, executable risk.
Authenticity Score: AI generation, deepfake/manipulation, provenance.
Trust Score: source, metadata, reputation, certificates and context.

### MVP user actions
- Scan link before download
- Quarantine
- Scan
- Release to Downloads
- Delete
- View details

### Future education mode
- Malware: block
- Phishing: block
- Unknown executable: require approval
- AI-generated content: allow + label
- Unknown source: warn
- Verified educational source: allow
